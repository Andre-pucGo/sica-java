# SICA - Sistema de Compartilhamento de Arquivos 📁

Este é um projeto acadêmico de Redes de Computadores desenvolvido para o curso de Análise e Desenvolvimento de Sistemas da Pontifícia Universidade Católica de Goiás (PUC Goiás).

O objetivo da aplicação é demonstrar na prática a comunicação entre Cliente e Servidor utilizando a arquitetura de **Sockets TCP** em Java. O sistema permite listar, enviar (upload) e baixar (download) arquivos de forma síncrona através de uma rede.

## 🚀 Tecnologias Utilizadas
* **Java:** Linguagem principal do projeto.
* **Sockets TCP:** Para comunicação confiável e orientada a conexão (`java.net.Socket` e `java.net.ServerSocket`).
* **I/O Streams:** Para leitura e escrita de dados e arquivos (`DataInputStream`, `DataOutputStream`, `FileInputStream`, `FileOutputStream`).
